# Sies2Csv


## What is this application in a nutshell?

_sies2csv_ is a small CLI tool that reads an Excel file containing a list of students enrolled in a course, generated by SIES (the platform used at the University of Oviedo), and converts it into a CSV file suitable for updating student rosters in [Classroom 50](https://github.com/foundation50/classroom50/wiki).

More specifically, although it can be used independently, _sies2csv_ is designed to generate a CSV file for use as input to the [roster50](https://github.com/raul-izquierdo/roster50) tool. Both tools are part of the [Classroom 50 Tools](https://github.com/raul-izquierdo/classroom-50-tools) toolkit.

It is implemented in Java and requires JDK 21 or later.

## Who is this for?

This tool is intended for lecturers who use [Classroom 50](https://github.com/foundation50/classroom50/wiki) and have access to the University of Oviedo's SIES platform.

## The Problem

The SIES platform allows lecturers to download an Excel file containing the list of students enrolled in their course. However, Classroom 50 requires the student list to be provided as a CSV file with a specific format. This means that the data in the Excel file must be filtered and cleaned, which can be a tedious and error-prone process when done manually.


## How does the app simplify this process?

_sies2csv_ automates the conversion process. It opens the Excel file downloaded from SIES and performs the following tasks:
- Checks that the file is an Excel file with the expected structure. If it does not use the SIES format, it reports the problem.
- Extracts the fields relevant to Classroom 50: the student's name, email address, and laboratory group. It reports any missing values.
- Cleans laboratory group names.
- Optionally removes all students who do not belong to the lecturer's laboratory groups.


## Installation

Download [sies2csv.jar](https://github.com/raul-izquierdo/sies2csv/releases/latest/download/sies2csv.jar) from the latest release of this repository.

To verify that it works, run the _version_ or _help_ command:

```bash
java -jar sies2csv.jar -V
```

```bash
java -jar sies2csv.jar -h
```

## Running the tool

First, download the _"alumnosMatriculados.xls"_ Excel file from SIES.

Then run:

```bash
java -jar sies2csv.jar
```


When reading the Excel file, the following types of rows are ignored, although each case is reported:
- Rows without an email address, which is required by Classroom 50.
- Rows without a student name. A name is not required by Classroom 50, but it is required by SIES, so a student without a name is considered a SIES error.

An unassigned laboratory group is not considered an error, because the process of assigning groups to students may not be complete yet. In addition, Classroom 50 allows students to be created without a group.

## Cleaning group names

Values in the Excel file's "_Prácticas de Laboratorio_" column contain a prefix that is not needed by _Classroom 50_. _sies2csv_ therefore cleans group names before generating the CSV file. Specifically, it removes the `Prácticas de Laboratorio-` prefix from each value and leaves the rest unchanged (without converting it to lowercase or making any other modifications).

Examples:
- "Prácticas de Laboratorio-01" -> "01"
- "Prácticas de Laboratorio-Inglés-02" -> "Inglés-02"
- "Prácticas de Laboratorio-Ing-03" -> "Ing-03"

Any additional group-name cleaning should be performed by the teacher in the generated CSV file before it is passed to _roster50_.

## Filtering by group

By default, all students in the Excel file are included in the generated CSV file. To include only students from specific groups ("_Prácticas de Laboratorio_" column), create a _groups.csv_ file listing the lecturer's groups.

Example _groups.csv_:
```csv
01
02
Ing-01
Ing-02
```

The file must have **no header**, with one group on each line.

> If you use _sies2csv_ together with [solutions50](https://github.com/raul-izquierdo/solutions50) (another tool in this toolkit), you can use that tool's _groups.csv_ file with _sies2csv_ even if it contains additional columns. _sies2csv_ reads only the first column (the group name) and ignores the others.

## Command-line arguments

Syntax:

```bash
java -jar sies2csv.jar [flags] [sies-file]
```

**sies-file** is the name of the Excel file downloaded from SIES. It can be omitted if the file is named `alumnosMatriculados.xls`.

Flags:
- **-z [output-roster.csv]**: The name of the generated CSV file. If not provided, defaults to `new-roster.csv` (the name expected by _roster50_).
- **-g [groups.csv]**: The file listing the groups to be considered for the teacher. Only students from the specified groups will be included in the output CSV. If not provided, defaults to `groups.csv` if it exists. If not, no filtering by group will be applied and all the students will be included in the output CSV.
- **-h, --help**: Show help.
- **-V, --version**: Show version.

## Exit Codes

The exit codes indicate the result of the command execution:
- **0**: The command executed successfully.
- **1**: An error occurred.
