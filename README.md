# Sies2Csv


This tool is intended for University of Oviedo lecturers who use [Classroom 50](https://github.com/foundation50/classroom50/wiki).

_sies2csv_ converts the Excel file generated by SIES (the University of Oviedo information system) to the CSV format required by [roster50.jar](https://github.com/raul-izquierdo/roster50) to update the Classroom 50 student roster.

For an overview of how this tool fits into the workflow, see the [roster50](https://github.com/raul-izquierdo/roster50) documentation. _sies2csv_ generates automatically the csv file required by _roster50.jar_ that otherwise would have to be created manually by the lecturer.

It is implemented in Java and requires JDK 21 or later.


## Installation

Download [sies2csv.jar](https://github.com/raul-izquierdo/sies2csv/releases/latest/download/sies2csv.jar) from the latest release of this repository.

To verify that it works, run the _version_ or _help_ command:

```bash
java -jar sies2csv.jar -V
```

```bash
java -jar sies2csv.jar -h
```

## Running the tool

First, download the _"alumnosMatriculados.xls"_ Excel file from SIES. This file contains the list of students enrolled in the course and will be converted to CSV.

Then run:

```bash
java -jar sies2csv.jar
```

A new file named `new-roster.csv` will be created containing the student list in the [format required](#step-1-obtain-the-updated-student-list-csv) by _roster50.jar_.

For example:
```csv
first_name,email,section
"Izquierdo Castanedo, Raúl", fakemail@gmail.com, g01
"González Pérez, Juan", fakemail2@gmail.com, english-02
"Alonso, Mariano", fakemail3@gmail.com, g01
...
```


The following rows in the Excel file are ignored, although each case is reported:
- Rows without an email address, which is required by Classroom 50.
- Rows without a student name. A name is not required by Classroom 50, but it is required by SIES, so a student without a name is considered a SIES error.

An unassigned laboratory group is not considered an error, since Classroom 50 allows students to be created without a group.

## Cleaning group names

Values in the Excel file's _Prácticas de Laboratorio_ column contain a prefix that is not needed by Classroom 50. _sies2csv_ therefore cleans group names before generating the CSV file.

Specifically, it removes the "Prácticas de Laboratorio-" prefix from each value and leaves the rest unchanged (without converting it to lowercase or making any other modifications).

Examples:
- "Prácticas de Laboratorio-01" -> "01"
- "Prácticas de Laboratorio-Inglés-02" -> "Inglés-02"
- "Prácticas de Laboratorio-Ing-03" -> "Ing-03"

Any additional group-name cleaning can be performed in the generated CSV file before it is passed to _roster50.jar_.

## Filtering by group

By default, all students in the Excel file are included in the generated CSV file. To include only students from specific groups (from the Excel file's _Prácticas de Laboratorio_ column), create a _groups.csv_ file listing the lecturer's groups.

Example _groups.csv_:
```csv
01
02
Ing-01
Ing-02
```

The file must have **no header**, with one group on each line.

> If you use _sies2csv_ together with _solutions50.jar_ (another tool in this toolkit), you can use that tool's _groups.csv_ file with _sies2csv_ even if it contains additional columns. _sies2csv_ reads only the first column (the group name) and ignores the others.

## Command-line arguments

Syntax:

```bash
java -jar sies2csv.jar [flags] [sies-file]
```

**sies-file** is the name of the Excel file downloaded from SIES. It can be omitted if the file is named `alumnosMatriculados.xls`.

Flags:
- **-z [output-roster.csv]**: The name of the generated CSV file. If not provided, defaults to `new-roster.csv` (the name expected by _roster50.jar_).
- **-g [groups.csv]**: The file listing the groups to be considered for the teacher. Only students from the specified groups will be included in the output CSV. If not provided, defaults to `groups.csv` if it exists. If not, no filtering by group will be applied and all the students will be included in the output CSV.
- **-h, --help**: Show help.
- **-V, --version**: Show version.

## Exit Codes

The exit codes indicate the result of the command execution:
- **0**: The command executed successfully.
- **1**: An error occurred.
